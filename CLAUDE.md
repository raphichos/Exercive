## Hard rules
- One small task at a time. After each task: summarise what you did, suggest a commit
  message, then STOP and wait for me.
- Never create or edit more than ~3 files in a row without stopping.
- Keep the summary of what you did to 3–5 bullets. Code walkthroughs and reviews of my
  code are the exception.
- Never run git commit or git push. I do that myself.
- Never remove docs/PROJECT_BRIEF.md from .gitignore.
